# Guilduo LPv2.1

LPv2の内容と体験を維持し、タスクの往復を動きで伝える比較版。日本語は `/lpv2-1/`、英語は `/lpv2-1/en/`。既存の `/lpv2/` と並存する。

`main.ts` はLPv2の体験ロジックを読み込み、`motion.ts` が独立して演出を追加する。`styles.css` もLPv2の基礎CSSを継承する。公式コピー、共通色、正式エンブレム、初期展開された接続説明を保持する。元のLPv2ファイルへ変更を加えない。

## 動きの意図

- Hero：人とAIを上下二本の直線でつなぎ、上段は依頼を右へ、下段は確認タスクを左へ送る。5.6秒周期でループし、中央のGuilduoは静止した中継地点として表示する。∞型の交差軌道は使わない。
- 見出しと本文：スクロールで各説明へ入ると、一度だけ短く浮かび上がる。本文を先に非表示にしない。
- 体験：タスク送信は右への小さな移動、AIからの依頼は下からの到着、修正された外部ボタンは一度だけ輪郭で強調、完了は二者の状態を順番に表示する。
- チームの式：`H + A = ✓`の記号が5.8〜6.6秒周期でゆっくり浮遊する。動くタイミングをずらし、上下移動は最大8px、揺れは2度以内に収める。
- MCPと担当交代の図：接続線をたどる演出をループし、テキストの往復を示す。
- 操作：CTAに小さなhover応答、接続説明に短い開閉表示を加える。スクロールの速度や位置は奪わない。

デモは模擬データのまま。Guilduoへ成果物を移動・表示する演出や、本物のAIへの接続は追加しない。

## モーション制御

ヘッダーの「動き ON / OFF」で演出を切り替える。スマホでは同じボタンを一時停止・再生アイコンで表示し、状態は`aria-pressed`でも伝える。選択は`guilduo-lpv21-motion`に保存する。端末のReduced Motionを優先し、変更も即時反映する。Hero、チームの式、MCP、担当交代の図は画面外で一時停止し、戻ると続きから再開する。非表示タブでは全演出を停止する。見出しの登場は一度だけ、体験デモはユーザーの操作で進める。JavaScript無効でも静止画・本文・リンクを利用できる。

## 参考と実際の確認範囲

2026-09-06に以下を確認した。サイトの素材やコードをコピーせず、テンポと移動の考え方を参照した。

- [Edge Drop](https://www.edgedrop.app/)：Heroのファイル群の浮遊、曲線に沿った配置、スクロールで次の説明へつなぐ構成をブラウザで確認。Guilduoではファイルをテキストのタスクに置き換え、往復の方向へ意味を持たせる。
- [DeepSeek Harness](https://deepseek.com/harness/en/)：Heroのゆっくりしたopacity／blurの立ち上がりと、スクロール後の説明構成を確認。Guilduoでは文字の鮮明さを保ち、opacityと短い移動でテンポを取り入れる。
- [OpenAI GPT-6 Astra](https://openai.com/index/gpt-6-astra/)：本文のみ取得。ブラウザは403となり、実際の動きは未確認。確認できたモーションとしては扱わない。
