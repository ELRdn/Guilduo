## Required native integration contract

The existing adapter API stays the integration boundary; no new OAuth protocol wrapper is needed. A host integration must demonstrate all of the following before closing this gate:

1. **Human action and exact identity.** A composed, human-only native command or client action supplies the actual receiving `agent.id`. No model arguments, typed session ID, workspace ID, most-recent session or fork inheritance may select the credential owner. The registry supplies the Agent object; actual UI-to-host admission still needs verification.
2. **Owned browser handoff and callback.** The host explicitly opens authorization after that action, owns an HTTPS or numeric-loopback HTTP listener with an explicit port, and passes the received URL directly to `finish` for the originating session. State/code/issuer checks stay in the existing adapter. Callback data and authorization URLs must not become command results, prompts, session events, logs, persistent files or telemetry. If using the generic server, establish route trust/admission separately; do not assume `webServer.register` includes the connection fence.
3. **Attempt lifetime.** A bounded pending attempt cancels on user cancellation, timeout, logout, exact session disposal and plugin unload; closes its callback owner; and clears credentials. Late callbacks, duplicate callbacks, old attempts and session switches cannot authenticate a replacement or fork. Cancellation cannot leave a callback listener or pending login alive.
4. **Safe output and failure.** Catch SDK/HTTP/browser failures at the human-command/UI boundary and report fixed non-secret text. The native registry persists thrown messages. Login must not start a model run, mint standing task permission, or imply server grant revocation on local logout.
5. **Native acceptance.** With a synthetic authorization server and the actual host command/client carrier, show explicit action → browser handoff → callback → exact-session tool admission, and reject an unauthenticated session/fork, wrong state/location/issuer, replay and post-disposal callbacks. Inspect native persisted events for credential absence. Current registry fixtures cover only the first primitive, not this complete flow.
