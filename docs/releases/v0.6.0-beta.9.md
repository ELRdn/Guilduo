# Guilduo v0.6.0-beta.9 — Quests views, calendar, notes and shared timer

This source release integrates the paused Guilduo work with the latest published main. It remains a public beta. Production deployment is tracked separately through the manual Worker and Site workflows; a source tag alone does not deploy either surface.

## Changes

- Home navigation, Quests board/list/Gantt, Calendar, Notes and a shared timer that remains available across screens. Network, Battle and Skills move into More; mobile navigation exposes Home, Quests, Calendar, Notes and More.
- Calendar month/week/day views, explicit recording and scheduling from mouse selection, keyboard selection or a touch hold. New selections require confirmation before saving.
- Private notes and time entries, conflict detection, timer operation receipts, history, daily/weekly/Quest summaries and export/import/deletion backed by D1. Quests continue using Appwrite.
- User-selectable local/Toggl time precedence, preserving legacy Toggl-first behavior for existing users and distinguishing zero, missing values and acquisition errors.
- Shared MCP Agent selection, optimistic Quest versions, prepared Appwrite transactions, OAuth persistence and deferred authenticated entry. Existing completion, reward and Human review boundaries remain independent.
- Latest published LP, SEO, consent-based public GA4, host extensions and asset-retention safeguards are preserved. DSH stability reports and remaining account acceptance are documented.

## Validation and boundaries

The integration is checked with root tests, TypeScript, design checks, generated API contracts, production builds and browser/CI verification. Production run IDs and acceptance are recorded in the integration report after actual publication.

Billing, Jev and linked launch analytics remain disabled. Their paid-launch acceptance and signed approval are separate from this free-beta release. Host extension versions are unchanged.

Physical touch/Pixel 9, cross-device Google authentication, real external Agent/Human round trips and prolonged observation are not accepted by synthetic browser or API tests. Private productivity storage currently uses an owner snapshot with a 900 KB ordinary-write budget and a 100 KB timer-stop reserve; larger datasets require a future storage migration, never silent truncation.

The active `claude/ux-new` branch is explicitly excluded from this integration and publication.
